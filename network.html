Computer Networks & Network Security 🌐

Understand computer networks, communication models and basic network security concepts.

Types of Computer Networks

LAN

Local Area Network connects computers within a small geographical area such as a school, office or building.

MAN

Metropolitan Area Network connects computers across a city or large geographical area.

WAN

Wide Area Network connects computers over large geographical areas. The Internet is a common example.

TCP/IP Reference Model

Internet

Basic Network Security

Firewall

A firewall monitors and controls incoming and outgoing network traffic.

Encryption

Encryption protects information by converting readable data into coded data.

Antivirus

Antivirus software helps detect and remove malicious software.
